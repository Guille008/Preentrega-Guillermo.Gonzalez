# 🌐 Preentrega – Proyecto Inicial HTML

Este proyecto fue desarrollado como primera entrega del curso de Desarrollo Web, enfocado exclusivamente en HTML y estructura básica de una página web.

Se mantiene en su versión original para mostrar la evolución en mi proceso de aprendizaje y el progreso desde mis primeros pasos en desarrollo web.

---

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3 básico
- Git & GitHub
- GitHub Pages (deploy)

---

## 📌 Objetivo del proyecto

El objetivo principal fue:

- Comprender la estructura semántica de HTML
- Organizar correctamente etiquetas y contenido
- Construir una página web estática
- Aplicar estilos básicos con CSS
- Publicar un proyecto en GitHub Pages

---

## 📄 Características

- Página web estática
- Uso de etiquetas semánticas
- Estructura clara de contenido
- Diseño básico inicial

---

## 🧠 Qué aprendí en este proyecto

- Estructura fundamental de HTML
- Buenas prácticas iniciales de maquetado
- Relación entre HTML y CSS
- Flujo básico de trabajo con Git
- Publicación de un sitio estático
